# Edge cases to test for any slug function

## Conclusion

A slug function looks trivial, but most bugs live in the same five places. Write one test per item before writing the regex.

## Checklist

- [ ] Punctuation between words (`Hello, World!` → `hello-world`).
- [ ] Runs of mixed separators (`a -- _ b`) collapse to a single hyphen.
- [ ] Leading and trailing separators are trimmed — no `-hello-`.
- [ ] Input that contains nothing slug-worthy (`!!!`, `""`) returns `""`, not `-`.
- [ ] Non-string input throws instead of slugifying `"null"` or `"42"`.

## When it applies

- Any ASCII slug for URLs, file names, anchors or IDs.

## When it does not

- Slugs that must preserve non-Latin scripts — the checklist is still useful, but the expected outputs differ.
