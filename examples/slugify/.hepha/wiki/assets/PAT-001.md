# Strip diacritics in JavaScript with NFKD + \p{M}

## Conclusion

To fold accented Latin letters to ASCII without a dependency:

```js
text.normalize("NFKD").replace(/\p{M}+/gu, "")
```

Prefer **NFKD** over NFD: it additionally folds compatibility characters (`ﬁ` → `fi`, full-width `ＡＢＣ` → `ABC`).

## When it applies

- Slugs, search keys, file names, sort keys for Latin-script text.
- Any Node.js ≥ 10 / modern browser (`\p{…}` needs the `u` flag).

## When it does not

- Letters that are not "base letter + combining mark" survive unchanged: `ø`, `ß`, `ł`, `æ`, `đ`. Handle them with an explicit table only if users need it.
- Non-Latin scripts are not transliterated (`你好` stays `你好`).
- Do not use it to display names — it is lossy.

## How to verify

```text
"Crème Brûlée" -> "Creme Brulee"
"ﬁnal ＡＢＣ"    -> "final ABC"
"Søren"        -> "Søren"   (unchanged, known limitation)
```
